# Селекторы страницы авторизации

| Элемент | Селектор | Причина выбора |
|---|---|---|
| Логин | id=username; name=username | Уникальные атрибуты, не зависят от оформления |
| Пароль | id=password; name=password | Уникальные атрибуты и явное имя поля |
| Вход | id=login | Стабильный идентификатор действия |
| Успешное состояние | id=dashboard | Проверяется видимость, а не только наличие в DOM |
| Выход | id=logout | Однозначный признак успешного входа |
| Ошибка | id=login-error | Позволяет проверить конкретный текст ошибки |

Не используем абсолютные XPath, позиционные CSS-селекторы и классы оформления как основную привязку. Ожидания Selenium проверяют видимость элементов; произвольные задержки в тестах не нужны.

Сервер выдаёт cookie учебной сессии при валидных данных. Дополнительные проверки: сохранение сессии при обновлении, выход и отказ при неверном пароле. Учётная запись student / Study123! опубликована как тестовая и не используется во внешних сервисах.
