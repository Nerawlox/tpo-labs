# Матрица решений контактной формы

Все поля обязательны. Имя и сообщение после trim должны быть непустыми; email должен иметь вид local@domain.tld без пробелов. Входные классы email: пустой, непустой неверного формата, валидный.

| Правило | Имя непустое | Email валиден | Сообщение непустое | Результат |
|---|---|---|---|---|
| D01 | Да | Да | Да | Сообщение успешно принято |
| D02 | Да | Да | Нет | Ошибка сообщения |
| D03 | Да | Нет | Да | Ошибка email |
| D04 | Да | Нет | Нет | Ошибки email и сообщения |
| D05 | Нет | Да | Да | Ошибка имени |
| D06 | Нет | Да | Нет | Ошибки имени и сообщения |
| D07 | Нет | Нет | Да | Ошибки имени и email |
| D08 | Нет | Нет | Нет | Ошибки всех полей |

В восьми параметризованных тестах невалидный email представлен пустым значением. Три дополнительных теста покрывают непустые неверные форматы: invalid, a@b, user @example.com. Для непустого неверного email ожидается «Введите корректный email», для пустого - «Email: обязательное поле».

Валидность полей независима: строки D01-D08 покрывают все комбинации трёх двоичных условий; варианты неверного формата email уточняют D03. Дополнительная проверка имени из пробелов подтверждает правило trim. Это конечная модель классов входов, а не перебор всех возможных строк.

Реализация: pages/base_page.py - общие ожидания и действия; pages/contact_page.py - локаторы и действия формы; test_contact.py - проверки результата. Ответ «принято» относится к локальному стенду; отправка настоящего письма не реализована.
