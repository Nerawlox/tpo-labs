# ЛР 6. Модульные тесты

Calculator реализует add, subtract, multiply, divide и is_prime_number. Арифметика принимает конечные вещественные числа, исключая bool; неподходящий тип вызывает TypeError, NaN/inf — ValueError. Деление на ноль вызывает ZeroDivisionError. Проверка простоты принимает только int, исключая bool; числа меньше 2 не простые.

Тесты: 16 арифметических примеров, 4 проверки деления на ноль, 10 примеров простоты, 4 проверки типа для простоты и 16 проверок неверных операндов. Всего 50 параметризованных случаев.

Для дробей применяется pytest.approx, исключения проверяются через pytest.raises. Запуск: `python scripts/run_tests.py lab06`. Логи, JUnit и техническая HTML-страница результата сохраняются в results.
