# ЛР 2. Исследование интерфейса и дефекты

## Ожидаемое поведение

1. Непустая задача добавляется, пробельная/пустая отклоняется.
2. Отметка меняет состояние именно выбранной задачи.
3. «Все» показывает все задачи, «Активные» — невыполненные, «Выполненные» — выполненные.
4. Удаляется задача выбранной строки.
5. Счётчик показывает число невыполненных задач.
6. Состояние сохраняется после обновления страницы. «Сбросить список» очищает данные.

Версия 1.0 содержит намеренные учебные дефекты и сохраняется без их исправления, чтобы баги можно было воспроизвести.

## Исследовательская сессия

Маршрут исследования: добавление обычной задачи → пустой/пробельный ввод → несколько задач → отметка выполнения → фильтры → обновление → удаление второй строки. Это последовательность исследования интерфейса с последующим оформлением сценариев, а не отдельный автотест требований без дефектов.

Чек-лист №1 адаптирован: арифметические операции заменены операциями списка, проверки пустого ввода и очистки сохранены. Конкретные сценарии UI01–UI07 и фактические результаты находятся в results/ui-checks.md. Для браузерных действий и снимков применён Selenium; ручной прогон человеком не заявляется.

## Обнаруженные дефекты

### BUG-01. Добавляется задача из одних пробелов

- Предусловие: открыть список, нажать «Сбросить список».
- Шаги: добавить «Подготовить тест-кейсы»; ввести три пробела; нажать «Добавить».
- Ожидалось: одна задача, пробельная задача не добавлена; валидация сообщает об ошибке.
- Получено: две строки, вторая без названия; счётчик равен 2.
- Severity: Minor. Priority: Medium. Статус: Open.
- Подтверждение: screenshots/02_blank_task_bug.png; сценарий UI02.

### BUG-02. Счётчик включает выполненные задачи

- Предусловие: сбросить список.
- Шаги: добавить «Подготовить тест-кейсы» и «Проверить приложение»; отметить первую выполненной.
- Ожидалось: «Осталось активных: 1».
- Получено: «Осталось активных: 2».
- Severity: Minor. Priority: Medium. Статус: Open.
- Подтверждение: screenshots/03_counter_bug.png; сценарий UI03.

### BUG-03. Фильтр «Выполненные» показывает активные задачи

- Предусловие: две задачи, первая выполнена, вторая активна.
- Шаги: нажать «Выполненные».
- Ожидалось: только «Подготовить тест-кейсы» с отметкой выполнения.
- Получено: только активная «Проверить приложение».
- Severity: Major. Priority: High. Статус: Open.
- Подтверждение: screenshots/04_completed_filter_bug.png; сценарий UI04.

### BUG-04. При удалении второй задачи удаляется первая

- Предусловие: сбросить список, добавить «Подготовить тест-кейсы» и «Проверить приложение», выбрать «Все».
- Шаги: нажать «Удалить» во второй строке.
- Ожидалось: осталась «Подготовить тест-кейсы».
- Получено: осталась «Проверить приложение», первая задача потеряна.
- Severity: Major. Priority: High. Статус: Open.
- Подтверждение: screenshots/07_delete_wrong_task_bug.png; сценарий UI07.

Окружение для всех багов: Windows, Chrome; точные версии, URL и время — results/ui-checks.json. Severity описывает влияние, Priority — рекомендуемый порядок исправления. Четыре FAIL в протоколе — ожидаемая фиксация учебных дефектов, а не успешное прохождение требований.
